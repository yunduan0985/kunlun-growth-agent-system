# 🎯 [CLOSE 系列] 逼单话术与客户异议处理原子拼图库

> [!IMPORTANT] 核心原则
> 永远不要硬推销。用「同理心 + 数据 + 案例 + 稀缺性」四步化解异议。

---

## 🧩 [CLOSE-01] 「太贵了」异议处理

**触发场景**：客户说"19800 太贵了，再想想"

**处理话术**：
```
"我完全理解你的感受，我当初也觉得这个数字不小。
  
但我想问你一个问题：你现在用传统方式处理 [客户业务痛点]，
每个月大概花多少时间和人力成本？

如果保守估计你们节省了一个全职员工（月薪 8000），
一年就是 9.6 万。第一个月就能回本。

而且我们还有 5:5 分润——你带来的客户，
利润一人一半，这个不是支出，这是投资。"
```

**输入**：客户说"太贵"  
**输出**：将客户思维从「成本」转换为「投资回报」

## 🧩 [CLOSE-02] 「没时间学」异议处理

**触发场景**：客户说"我太忙了，没时间学"

**处理话术**：
```
"你说忙，我特别理解。我们的学员 90% 都是老板，
全都说自己很忙。

但我们的 4 天体验营每天只需要 1 小时。
而且你不需要「学会」——你只需要「用起来」。

我们帮你配置好，你只需要按按钮，就像用微信一样简单。
最忙的老板，反而是最需要数字员工的那个人。"
```

---

## 🧩 [CLOSE-03] 「再考虑考虑」异议处理

**触发场景**：客户说"我再想想"（通常意味着还有顾虑未解决）

**处理话术**：
```
"当然，这个决定值得认真想。
  
不过我想直接问你——是价格这块你还有顾虑，
还是对我们能不能真的帮到你这个行业还不确定？

如果是后者，我可以现在就给你演示一下，
把你最头疼的一个业务场景，我当场用 AI 解决给你看。
你再做决定也不迟。"
```

---

## 🧩 [CLOSE-04] 「我不懂技术」异议处理

**触发场景**：客户说"我不懂 AI，这个太难了"

**处理话术**：
```
"我们的学员里 80% 都是完全不懂技术的。

我给你看看这个校长——[展示案例截图]
她连电脑都用得不太熟练，现在用我们的系统
已经帮她节省了 2 个老师的工时。

你不需要懂技术。就像你用微信不需要懂编程一样。
我们帮你把所有技术的部分装好，你只需要告诉它'帮我做什么'。"
```

---

## 🧩 [CLOSE-05] 「稀缺性逼单」话术

**触发场景**：客户犹豫，需要制造决策紧迫感

**处理话术**：
```
"我需要告诉你一个实情——
这期 Day 4 的 5:5 共创合伙人名额只剩 [X] 个了。

因为合伙人要对接的是我们团队，我们有精力深度服务的
每一期只有这么多。

而且今天签约的话，我额外送你 [价值XXXX元的增值内容]。
下一期要等 [X] 周，价格不确定会不会调整。

你现在的一个决定，可能是未来半年最好的投资。"
```
