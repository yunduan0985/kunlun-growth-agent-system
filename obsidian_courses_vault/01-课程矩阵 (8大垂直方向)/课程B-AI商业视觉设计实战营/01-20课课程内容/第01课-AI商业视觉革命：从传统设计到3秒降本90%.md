第四节 步骤分解与手把手实操 SOP

步骤一：产品线稿与 ControlNet 深度图准备
提取【高端奢华珠宝首饰渲染】的基础矢量线稿或 Depth 深度图，确保边缘清晰无杂色。

步骤二：配置专用的商业视觉 Prompt（提示词）
请在工作台中输入以下顶级商业打光提示词：

```markdown
# Role: 顶级商业摄影与视觉设计 Agent
## Context: 针对品类 [高端奢华珠宝首饰渲染]

## Prompt Specs
Commercial product photography of [高端奢华珠宝首饰渲染], studio lighting, soft rim light, 8k resolution, photorealistic, octanerender style, metallic and glass texture, professional composition, --ar 16:9 --v 6.0 --style raw

## Constraints
1. 严禁出现杂乱背景与畸变线条；
2. 光影方向必须与产品主结构线稿 100% 契合；
3. 确保颜色符合品牌 VI 标准色值。
```

步骤三：ComfyUI 节点运行与分辨率校验
调用 Python 验证脚本：

```python
def validate_image_resolution(width, height):
    if width < 3840 or height < 2160:
        return False, "分辨率未达到 4K 商业印刷标准"
    return True, "PASS"
```
