P04｜AI的价值，不是让教师少做，而是把时间用在更重要的地方

建议时间：1分20秒

标准版逐字稿

AI的价值，不是让教师少做，更不是让教师少负责，而是重新分配注意力。模板生成、信息整理、重复改编，这些标准相对清楚的工作，可以先交给AI。课堂互动、学生观察、专业判断和情感沟通，必须留给教师。我们真正要节省的，不是教育本身，而是那些挤占教育时间的重复劳动。省下来的时间，要重新投入到学生身上。

60–75分钟压缩版

P05｜AI在教学中，主要发挥四种能力

建议时间：1分30秒

标准版逐字稿

在教学工作中，AI主要发挥四种能力。生成，是从零到一得到初稿；分析，是从杂乱信息里找到反复出现的线索；改编，是让一份内容适配不同对象和格式；个性化，是围绕同一个知识点形成不同支架和难度。不要只把AI理解成写文章的工具。生成只是起点，分析、改编和个性化，才会持续放大教师的工作效率。

四种核心能力是生成、分析、改编和个性化。生成只是起点。

P06｜AI增强教师，而不是替代优秀教师

建议时间：1分40秒

标准版逐字稿

这里是第一课最重要的边界：AI增强教师，而不是替代优秀教师。重复整理、归纳和初稿生成可以交给AI；启发、情感、价值观和课堂判断必须由教师承担。AI负责提速，教师负责方向与结果。如果生成内容最后进入了课堂、作业或家校沟通，那么责任不会因为它由AI生成而转移。

60–75分钟压缩版

AI负责提速，教师负责方向、判断和最终结果。

互动 / 讲师动作

标准版逐字稿

P14｜材料越长，越需要先把信息整理成结构

建议时间：1分20秒

标准版逐字稿

面对教材、教案和教研材料这类长文本，不要只问‘帮我总结’。更稳的方法是让AI先阅读，再提取，再归纳，最后按你需要的结构输出。长材料处理的价值，是把散落信息变成可用结构，而不是让AI替教师判断哪些内容适合课堂。材料越长，越要给清楚范围和输出格式。

60–75分钟压缩版

P17｜一个模糊的指令，只会得到一个模糊的回答

建议时间：1分20秒

标准版逐字稿

如果输入的是‘帮我写一份教案’，AI并不知道教谁、教多久、解决什么目标、用什么格式交付。对象未知、标准未知、格式未知，处理过程自然不确定。模糊指令得到模糊回答，不是AI故意敷衍，而是任务条件没有说清。提示词的第一原则，不是写得长，而是把影响结果的条件补齐。

60–75分钟压缩版

对象、标准和格式没说清，AI只能猜。模糊输入必然带来模糊输出。

互动 / 讲师动作

P18｜一条可用的提示词，要说清四件事

建议时间：2分钟

标准版逐字稿

一条可用提示词要说清四件事：角色、任务、要求和输出格式。角色告诉AI以什么专业身份工作；任务说明要完成什么；要求规定对象、范围、质量和限制；输出格式决定结果怎样呈现、怎样检查。比如：你是一名初中语文备课助理，请生成45分钟教案初稿，目标清楚、活动可执行，不确定处标记待确认，用表格输出。这样AI才得到一份可执行的工作说明书。

60–75分钟压缩版

提示词四字段：角色、任务、要求、输出格式。它是一份工作说明书。

互动 / 讲师动作

转场

P19｜提示词不是越长越好，而是信息越完整越好

建议时间：1分40秒

标准版逐字稿

对比这两条提示词。左边只有‘帮我写一份教案’，右边明确了教师身份、八年级、45分钟、目标、流程、互动、作业和表格格式。右边不一定更华丽，但信息更完整，因此输出更容易审核和修改。提示词不是越长越好，而是关键条件越完整越好。以后优化提示词，不要先堆修饰词，先检查对象、时长、内容和格式。

同一输入包可生成教案、课件大纲、活动卡和反馈初稿，但要分别审核。

互动 / 讲师动作

请学员选择自己下一步最需要的一种交付物。

转场

无论生成什么，教师审核都是质量门。



P46｜教师审核不是最后一步，而是质量门

建议时间：2分钟

标准版逐字稿

教师审核不是最后补一个签字，而是一道质量门。AI初稿结构完整，仍然属于待确认状态；只有通过目标一致、事实准确、学生适配和表达得体四项检查，并完成修订，才成为可用版本。稳定流程应该是生成、审核、修订、使用、留存。审核不通过，就退回修改，不进入课堂。

60–75分钟压缩版

初稿通过四项质量门并完成修订，才能成为可用版本。

互动 / 讲师动作

演示一项不通过质量门的内容如何退回修改。

转场

把这条路径固定下来，就形成Workflow。



P47｜Workflow不是多问几次，而是固定可重复路径

建议时间：1分40秒

标准版逐字稿

Workflow不是把同一问题多问几次，而是每次都按固定顺序完成。随机对话依赖灵感，结果难复制；Workflow明确输入、步骤、审核和输出，下一次可以直接复用。它的价值不是让每次结果完全一样，而是让关键条件和质量门不被遗漏。

60–75分钟压缩版

Workflow是固定输入、步骤、审核和输出的可重复路径，不是多问几次。

互动 / 讲师动作

请学员比较自己刚才的随机对话与固定路径差在哪里。

转场

以备课为例，Workflow可以固定为五步。



P48｜一次备课Workflow，固定五个步骤

建议时间：1分50秒

标准版逐字稿

一次备课Workflow固定五步：收集目标、教材和学生情况；用角色、要求和格式说明任务；生成可修改框架；教师删减、重排和补充；最后按命名、标签和状态保存版本。请注意，保存也是流程的一部分。没有版本和审核状态，下次找到文件时仍然不敢复用。

60–75分钟压缩版

备课五步：输入包、说明任务、生成框架、教师审核、保存版本。

互动 / 讲师动作

请学员圈出自己最容易省略的一步。

转场

命题任务同样需要先固定条件，再讨论生成。



P49｜命题Workflow，先锁定条件再生成题目

建议时间：1分40秒

标准版逐字稿

命题Workflow先准备规格卡：知识点、题型、难度、题量、答案和解析。条件锁定后，AI生成候选题，教师再复核答案是否正确、难度是否合适、表述是否清楚。生成速度只有在规格明确、复核严格时才有价值。命题关系到学生评价，绝不能把候选题未经核验直接投入使用。

60–75分钟压缩版

命题先锁定规格，再生成候选题，最后复核答案、难度和表述。

互动 / 讲师动作

给出一道候选题，让学员按三项标准判断。

转场

要稳定复用，不能只保存一句Prompt。



P50｜稳定复用的最小单元，是一套任务包

建议时间：1分30秒

标准版逐字稿

稳定复用的最小单元是一套任务包，包括Prompt模板、审核清单、教师修改后的合格样例和命名规则。只保存Prompt，下一次仍然不知道什么结果算合格；只保存成品，又不知道当时用了什么条件。任务包让一次尝试升级为模板复用、Workflow和知识资产。

60–75分钟压缩版

可复用任务包包含Prompt、审核清单、合格样例和命名规则。

互动 / 讲师动作

请学员列出自己任务包中已经有和还缺的材料。

转场

最后一章，把审核后的好结果沉淀为知识资产。



06｜沉淀知识资产


本章页码：P51–P56

P51｜把好结果留下来，变成自己的知识库

建议时间：45秒

标准版逐字稿

进入第六章。真正长期有效的，不是AI曾经给过一次好回答，而是教师审核后把结果留下来。保存结果的同时，还要保存来源、版本和审核状态。只有这样，它才可能在下一次教学任务中被安全复用。

60–75分钟压缩版

第六章把审核后的好结果沉淀成可追溯资产。

互动 / 讲师动作

请学员想一个自己曾经做得很好但后来找不到的文件。

转场

知识库首先不是文件数量问题。



P52｜知识库不是文件堆，而是可检索、可复用的教学记忆

建议时间：1分30秒

标准版逐字稿

知识库不是文件堆。文件很多但找不到，只是存储；目录和命名清楚，才可检索；带来源、版本和审核状态，才可判断；能够进入下一次任务，才真正可复用。价值提升路径是保存、找到、判断、复用。数量不是目标，未来的自己看得懂、找得到、敢使用才有价值。

60–75分钟压缩版

知识库要经历保存、找到、判断、复用，文件多不等于资产多。

互动 / 讲师动作

请学员判断自己的文件目前停在哪一级。

转场

教师知识库可以先从五类常用资产开始。



P53｜教师知识库，可以从五类常用资产开始

建议时间：1分10秒

标准版逐字稿

教师知识库可以先保存五类资产：教材与资料、教案与课件、题目与答案、学生案例、教学反思。不要一开始就追求把全部历史文件搬进去。优先保存真正使用过、经过审核、未来有复用价值的内容。学生案例必须匿名化，题目与答案必须核验，反思要保留真实使用背景。

60–75分钟压缩版

先从教材资料、教案课件、题目答案、匿名学生案例、教学反思五类资产开始。

互动 / 讲师动作

请学员选择本周最先整理的一类资产。

转场

资产要能被找到，必须建立清晰结构和命名。



P54｜知识库必须让未来的自己找得到

建议时间：1分30秒

标准版逐字稿

知识库结构可以按学科、年级、单元和课时逐层组织。文件名至少包含学科、年级、单元、课时、类型、版本和审核状态。比如：语文_八年级_某单元_课时01_教案_v03_已审核。好命名不是形式主义，它能让未来的自己在几秒内判断这是什么、是否最新、能不能使用。

60–75分钟压缩版

文件名包含学科、年级、单元、课时、类型、版本和审核状态。

互动 / 讲师动作

请学员把一个真实文件名改成可检索命名。

转场

除了文件名，还需要一张教学资产记录卡。



P55｜只有带来源、版本和审核状态的内容才是资产

建议时间：1分40秒

标准版逐字稿

一项内容进入知识库前，至少记录名称、适用场景、来源、版本、标签、审核人、最后使用时间和状态。入库质量门有三项：来源可追溯，版本与审核状态可确认，场景与标签足以支持复用。流程是AI生成、教师审核、修订、标记、入库。没有来源和审核状态的内容，只能算草稿，不能算正式资产。

60–75分钟压缩版

资产必须可追溯、可确认、可复用；没有来源、版本和审核状态不能正式入库。

互动 / 讲师动作

请学员回答：没有审核状态的内容能否直接复用？

转场

当使用、审核、沉淀和复用连接起来，就形成知识飞轮。



P56｜使用、审核、沉淀、复用，形成教师的知识飞轮

建议时间：1分40秒

标准版逐字稿

知识飞轮有四步：把真实任务带入使用；审核事实和课堂适配；记录来源、版本和修改；在下一次任务中复用。每一次复用又会产生新的课堂反馈，继续完善资产。这样我们不再每次从零开始，而是让审核后的好做法越来越快、越来越稳，也越来越像自己的教学。

60–75分钟压缩版

知识飞轮是使用、审核、沉淀、复用，让每次真实任务改善下一次。

互动 / 讲师动作

请学员选择本周能够补上的一个飞轮环节。

转场

第一课到这里，可以收束为四个结论。



07｜总结与行动


本章页码：P57–P60

P57｜第一课，请记住四个结论

建议时间：2分钟

标准版逐字稿

第一课请记住四个结论。第一，AI是助教，先把重复劳动交出去；第二，从真实任务开始，不从功能清单开始；第三，AI初稿必须经过教师专业判断；第四，把有效做法留下来，变成任务包和资产。完整起步路径是：选任务、准备输入、写清Prompt、审核结果、保存做法。

60–75分钟压缩版

四个结论：AI是助教、从任务开始、教师把关、留下方法。

互动 / 讲师动作

全员用一句话复述自己带走的核心结论。

转场

最后把结论变成一个15分钟课后行动。



P58｜课后作业：完成你的第一次真实AI任务

建议时间：3分钟

标准版逐字稿

课后作业不是再收藏模板，而是完成一次真实AI任务。两分钟选择本周真实工作，三分钟准备目标、材料和学生情况，三分钟发送Prompt，五分钟圈出可用点与需修改点，最后两分钟保存输入、输出、修改和版本。完成标准有四项：任务真实、输入不含敏感信息、结果经过教师修改、留下可复用版本。完成一次，胜过收藏十个模板。

60–75分钟压缩版

15分钟作业：选择真实任务、准备输入、发送Prompt、教师审核、保存记录。

互动 / 讲师动作

请学员现在写下任务名称和计划开始时间。

转场

接下来用任务、输入和审核三个框架进入Q&A。



P59｜Q&A｜把你的真实教学任务带进来

建议时间：5分钟

标准版逐字稿

现在进入Q&A。请不要先问某个按钮在哪里，我们优先讨论三个问题：你想让AI完成什么任务；你已经有哪些材料和条件；什么标准决定结果能不能用。提问时尽量包含学科、年级、任务和限制。现场问题我会先归类，再回答：如果问题属于任务不清，我们先改任务；属于输入不足，我们先补条件；属于结果风险，我们用审核清单判断。

60–75分钟压缩版

Q&A按任务、输入、审核三类回答，优先解决真实教学问题。

互动 / 讲师动作

每类优先回答1个代表性问题；标准版可继续开放追问。

转场

最后用一句话结束第一课，并约定行动。



P60｜把重复劳动交给AI，把教育判断留给教师

建议时间：1分钟

标准版逐字稿

第一课结束前，请大家再记住这句话：把重复劳动交给AI，把教育判断留给教师。下一步不需要再学十个工具，只需要选择一个真实任务，完成输入、生成、审核、保存闭环。教师的价值，不在于亲手做完所有工作，而在于把时间用在真正需要教师的地方。请按第58页完成作业，我们在下一课用AI进入真实备课。谢谢大家。

60–75分钟压缩版

把重复劳动交给AI，把教育判断留给教师。完成一次真实闭环，下一课进入AI备课。

互动 / 讲师动作

再次提醒作业提交要求和时间；感谢学员。

转场

课程结束。
