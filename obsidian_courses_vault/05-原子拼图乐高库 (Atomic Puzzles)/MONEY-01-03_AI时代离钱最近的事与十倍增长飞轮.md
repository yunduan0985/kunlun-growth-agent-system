## 🧩 [MONEY-01] 离钱最近的3条路径

### 路径1：AI本地知识库 → B端签单
- **目标客户**：传媒公司、知识博主、律师、教培机构
- **核心价值**：帮客户把历史内容/专业知识做成会「学你风格」的AI员工
- **变现速度**：2个月内可签单，单价5万+
- **参考案例**：H船长，2个月0→6万

### 路径2：企业AI场景闭环 → 私有化部署
- **目标客户**：有真实业务痛点的中小企业主
- **核心价值**：不卖工具卖结果，一个场景省6位数人力
- **变现速度**：1个月可跑通第一单，单价3.98~10万
- **参考案例**：森马AI 400+场景，近1亿GMV

### 路径3：内容自动化 → 教学变现
- **目标客户**：内容创作者、MCN机构、直播团队
- **核心价值**：Cursor + 知识库，批量复制爆款风格
- **变现速度**：先服务自己，再服务他人
- **参考案例**：鹿书野，B站内容工厂，月GMV500万+

## 🧩 [MONEY-02] 从0到第一单的最快路径

```
Week 1-2: 找到自己最懂的一个行业
  → 不要「什么都能做」，只说「我专门做XX行业」

Week 2-3: 访谈3个目标行业的人
  → 问：「你每天最重复、最烦、最想甩掉的工作是什么？」

Week 3-4: 免费/低价帮1个种子客户解决这个问题
  → 跑通整个流程，记录节省的时间/人力

Month 2: 拿着量化数据开始正式收费
  → 「帮某某客户节省了X万人力成本」比任何广告都有效

Month 3+: 口碑裂变
  → 每个满意客户结束时说：「如果觉得还不错，最好支持是介绍朋友来」
```

## 🧩 [MONEY-03] 十倍增长的3个飞轮

### 飞轮1：服务飞轮
```
超预期交付 → 客户满意 → 主动转介绍 → 新客户 → 超预期交付（循环）
```

### 飞轮2：投流飞轮
```
先找自然成交率最高的内容
  → 投流放大（不是随便投）
  → ROI正 → 加量
  → 流量增加 → 成交增加 → 利润增加 → 继续投（循环）
```

### 飞轮3：价格飞轮（最反直觉）
```
涨价30~50%
  → 筛掉消耗心力的低价客户
  → 精力集中在高质量客户
  → 服务质量提升 → 口碑更好 → 转介绍更多
  → 可以继续涨价（循环）
```
