## 📋 模板一：5:5 场景共创合伙人协议（简版）

```markdown
昆仑增长 AI 场景共创合伙协议

甲方（技术方）：昆仑增长（Kunlun Growth）
乙方（场景方）：_______________
签署日期：______年______月______日

一、合作范围
乙方提供行业垂直场景与客户资源，甲方提供 AI 系统技术开发与部署服务。

二、收益分配
双方约定对合作产生的净利润按以下比例分配：
- 甲方（技术+运营）：50%
- 乙方（场景+客户）：50%
净利润 = 项目总收入 - 甲方技术服务成本（含服务器、API费用）

三、结算周期
每月 1 日进行上月利润结算，3 个工作日内完成转账。

四、保密义务
双方对合作过程中涉及的客户信息、技术方案等严格保密，违约方需赔偿等额损失。

五、协议有效期
本协议自签署之日起生效，有效期 12 个月，到期前 30 天可续签。

甲方签名：_______________ 日期：_______________
乙方签名：_______________ 日期：_______________
```

## 💰 收款操作 SOP

### Step 1：确认意向后立即发送报名确认函
- 学员口头答应 → 当场截图/PDF 签字 → 立即告知收款账户

### Step 2：收款后 5 分钟内发送权益激活包
- 自动触发：课程文件包链接 + 社群二维码 + 服务开始时间

### Step 3：7 天内安排第一次 1V1 深度诊断通话
- 了解学员行业 + 业务痛点 → 为 5:5 共创签约做准备
