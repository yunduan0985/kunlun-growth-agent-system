# 🧩 原子拼图块 [COURSE-A-PUZZLE]：跨境客服尺码引导换码降退货率原子块

> [!TIP] 拼图定位
> **分类**：课程拼图  
> **作用**：一键拦截尺码不合退货并引导免费补发

---

## 📥 输入参数 (Input)
```text
买家退货留言
```

## ⚙️ 拼图核心内容与 Prompt/SOP 代码 (Puzzle Code)
```text
提示词：买家称服装偏小要退货。客服表达诚挚歉意，并提供【免费补发大一码/免寄回】方案，降低 30% 退货损失。
```

## 📤 输出结果 (Output)
```text
阻截成功与换码安排
```
