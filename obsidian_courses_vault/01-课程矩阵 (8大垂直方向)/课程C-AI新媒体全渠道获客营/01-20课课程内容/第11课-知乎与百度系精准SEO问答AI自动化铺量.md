第四节 步骤分解与手把手实操 SOP

步骤一：选题抓取与情绪共鸣点提取
从对标账号中提取最火的 3 个卖点与买家最痛的 2 个情绪触发词。

步骤二：配置专用的去 AI 味高转化 Prompt（提示词）
复制以下提示词到 AI 控制台：

```markdown
# Role: 顶级新媒体获客操盘手 Agent
## Context: 针对产品 [B2B企服与高客单咨询获客]

## Constraints (去 AI 味铁律)
1. 绝对禁止使用任何 AI 腔词汇（如：此外、综上所述、值得注意、深远意义、赋能、生态）；
2. 每句不超过 15 个字，单句独立换行，充满真实对话感；
3. 第一句必须是强烈反差或意外数据（如：“说实话，做这件事之前没想到会走到这一步”）；
4. 结尾必须带有低门槛行动号召（CTA）。

## Input Data
- 核心素材：问答长尾流量缺失、长尾词覆盖不足、引流效果差
- 目标受众：针对 B2B企服与高客单咨询获客 买家

## Workflow
1. 提取反差感故事线；
2. 采用口语短句排版；
3. 检查并切断所有 AI 腔调。
```

步骤三：意向客户自动提取与风控审查
调用 Python 脚本审查评论区：

```python
def extract_leads(comment_text):
    keywords = ["怎么买", "求链接", "怎么报名", "私信"]
    for k in keywords:
        if k in comment_text:
            return True, f"命中意向词: {k}"
    return False, "普通评论"
```
