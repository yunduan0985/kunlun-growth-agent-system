第四节 步骤分解与手把手实操 SOP

步骤一：原始数据整理与提取
首先，我们需要把【智能割草机器人】的基础信息与竞品热词提取出来。
数据结构要求：
1. 产品核心材质与功能参数；
2. 目标市场（如北美/欧洲/日本）的文化避讳与语言习惯；
3. 买家最关注的 3 个核心卖点与最讨厌的 2 个缺陷。

步骤二：配置专用的结构化 Prompt（提示词）
请打开 AI 控制台，复制以下专属提示词：

```markdown
# Role: 跨境电商 差评分析与VOC客户声音AI挖掘改进产品 顶级专家 Agent
## Context: 针对品类 [智能割草机器人]

## Objectives
帮助卖家在 [差评分析与VOC客户声音AI挖掘改进产品] 场景中，生成高转化、零AI味、地道本土化的交付内容。

## Constraints (去 AI 味铁律)
1. 严禁使用任何生硬的 AI 腔调词汇（如：Furthermore, In conclusion, Delve, Supercharge, Unwavering）；
2. 采用短句表达，单句独立换行，主谓宾结构清晰；
3. 第一句必须是强烈吸引眼球的破折叠 Hook；
4. 严格遵守目标国的计量单位与语言习惯。

## Input Data
- 产品名称：智能割草机器人
- 核心痛点：无法快速从几千条1-3星差评中找到产品缺陷、产品迭代滞后

## Execution Flow
1. 深入分析买家心理；
2. 采用本土化口吻改写；
3. 检查合规与风险；
4. 格式化输出。
```

步骤三：运行自动化验证器校验
生成完毕后，调用验证脚本运行：

```python
# 自动化质检脚本
def check_quality(text):
    forbidden = ["furthermore", "in conclusion", "delve"]
    for w in forbidden:
        if w in text.lower():
            return False, f"包含禁词: {w}"
    return True, "PASS"
```
