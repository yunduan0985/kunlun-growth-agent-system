# 🧩 [VIRAL-05] YouTube 高 RPM 无露脸叙事视频全套 Prompt 库

> 本 SOP 提炼自栗子 10 万播放爆款经验，涵盖逆向拆解、爆款选题、Level 级分段脚本与逐句 FLUX/Midjourney 生图与 Video 动效 Prompt 标准模板。

---

## 🎯 1. 核心流程与工具配比

```
[对标拆解] ──> Gemini / Claude (逆向分析 30秒 Hook & 留存机制)
      │
      ▼
[选题生成] ──> 万能选题 Prompt (财富等级 / 命运分叉 / POV 沉浸感)
      │
      ▼
[脚本创作] ──> Claude (Level 1 到 Level 10 电影感递进脚本, 1900字)
      │
      ▼
[合规审查] ──> ChatGPT (YouTube 商业化原创性与降权审查)
      │
      ▼
[生图与视频] ──> FLUX / AutoJourney 批量下载 (分句输出 EN+CN 生图 Prompt)
```

---

## 🛠️ 2. 逐句分镜 Prompt 语法结构模版

对于脚本中的每一句台词，输出三件套：

```markdown
## {句号编号}. Script Sentence
{英文台词/中文台词}

### Image Prompt — English
Subject: {角色特征统一描述: same young male finance character, messy brown hair, white shirt, red tie, navy jacket}, {场景动作/道具}, {情绪表现}. Art Style: {风格统一限定: intentionally simple, low-detail rough YouTube finance explainer animation, thick black outlines, flat colors, minimal shadows, not cinematic, not Pixar}.

### 图片生成 Prompt — 中文
主体：{同一个角色描述}，{场景动作与道具}。艺术风格：刻意简单、低细节、粗糙的 YouTube 财经解释类动画风格，粗黑描边，扁平颜色。

### Video Prompt — English
Continue from the previous shot with the same character design. {微动效动作: limited puppet-like motion, slight blink, tiny head tilt}. Camera: {慢速推拉: slow subtle push-in or tiny horizontal pan}.
```
