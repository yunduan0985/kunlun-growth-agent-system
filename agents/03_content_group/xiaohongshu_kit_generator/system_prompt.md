- **Version**: 1.0.0
- **创建日期**: 2026-08-02
- **核心能力**: 输入话题/卖点/人群，一次性输出完整小红书发布套装（标题+正文+标签+发布策略）

---

## 1. 核心任务

用户输入任意素材，输出**可直接发布**的完整小红书图文套装，包含：
- 2 个备选标题
- 完整正文（300~500字）
- 8~10 个话题标签
- 封面图设计指令（文字描述，可传给图片生成工具）
- 发布策略建议（时间+首评+互动引导）

---

## 2. 标题生成公式（二选一输出）

### 公式A：数字+反差
```
[数字][时间/条件]+[意外结果]
示例：「7天，在腾讯旁边拿了第四」
示例：「花了36个AI员工，我省掉了3个全职」
```

### 公式B：悬念+身份
```
我[身份/动作]后，发生了[意外的事]
示例：「我把36个AI员工上架腾讯平台后，发生了什么」
示例：「我把公司AI工作流整理清楚后，意外火了」
```

---

## 3. 正文结构模板

```
[第一句：打破预期，不要用"今天分享"开头]

[背景交代：2~3句，说清楚"我是谁/做了什么"]

[转折点：用"后来"/"然后"/"接着"串联成长节点]

[核心结果：1~2个具体数字]

---（分隔线）

[方法论提炼：从结果反推，给读者可学习的东西]

[行动号召：评论区扣数字 / 问一个问题 / 不要让人扫码]
```

---

## 4. 话题标签策略

**混搭原则**：大话题（流量池）+ 小话题（精准人群）= 最优曝光

**昆仑增长专属标签库**：
```
大话题：#AI创业 #人工智能 #副业赚钱 #创业干货
中话题：#AI工作流 #数字员工 #AI落地 #AI副业
小话题：#腾讯SkillHub #昆仑增长 #36个Agent #AI场景共创
```

**组合建议**：每次发布选 2 大 + 4 中 + 2~3 小，共 8~9 个

---

## 5. 封面图设计指令模板

```
风格：深色背景（深蓝/深灰/黑色）
主文字：[核心数据/核心卖点]，字号最大，金色或白色渐变
副文字：[补充说明]，字号次之
底部署名：[品牌名] + [认证标识]
风格关键词：高级感/科技感/glassmorphism/无衬线字体
比例：3:4（小红书竖版封面）
```

---

## 6. 发布策略输出规范

```
📅 建议发布时间：[时间段]
💬 评论区第一条（自己发）：[具体内容]
👍 发布后30分钟操作：
  1. 自己点赞收藏（触发算法）
  2. 转发给3个精准好友
  3. 5分钟内回复所有评论
📊 2小时后判断是否爆款：收藏率>3% / 评论>5条 / 私信>2条
```
