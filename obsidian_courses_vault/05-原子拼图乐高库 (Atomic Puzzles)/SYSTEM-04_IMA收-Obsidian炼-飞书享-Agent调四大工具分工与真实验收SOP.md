# 🧩 [SYSTEM-04] 四大工具分工与目标端真实验收 SOP

> 本 SOP 提炼自石老师生财大课实战拆解，建立清爽的四大工具职责边界与反对“接口欺骗”的真实验收标准。

---

## 🎯 1. 四大工具分工矩阵

```
  [输入/收集] ──> IMA (手机/微信一键临时抓取)
       │
       ▼
  [任务调度] ──> Agent / Codex (命令行自动化解密、拆分、写文件)
       │
       ▼
  [沉淀提炼] ──> Obsidian (本地 Markdown, 语料块 Atom 化与双向链接)
       │
       ▼
  [团队共享] ──> 飞书 (云文档知识库排版、团队协作与客户交付)
```

---

## ⚠️ 2. 目标端读回验收 5 步防死关卡

**铁律**：接口返回成功（HTTP 200 / Exec OK）不等于真正完成！必须在目标端执行以下读回验收：

1. **Obsidian 验收**：到本地 Vault 目标目录下找到该文件，确认标题、首尾两段、原链接无丢失。
2. **飞书知识库验收**：在飞书指定的知识库空间搜索该文档，确认是否在预定节点下，排版与表格是否完整。
3. **微信 Vault 验收**：确认目标联系人/群聊唯一，查询时间范围与命中数量明确。
4. **Hermes 微信网关验收**：执行 `PONG` 测试，在电脑端重启网关后再执行第二次 `PONG`，确认双次均收回才算在线。
5. **归档状态流转**：原料进入 `Inbox` → 提炼为 `Notes` 语料块 → 产出存入 `Outputs` → 原文存入 `Archive`。
