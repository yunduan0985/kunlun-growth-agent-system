# 🧩 [TRAFFIC-04] 小红书四路搜索取证与爆款选题挖掘 SOP

> 本 SOP 提炼自叁斤实战拆解，通过四维度精准搜索全网痛点，自动捕获从“发现问题”到“准备买单”的完整需求链路。

---

## 🎯 1. 四路搜索关键词匹配矩阵

```
用户需求进化链路：
发现问题 (求助类) ──> 遇到卡点 (吐槽类) ──> 对比方案 (替代类) ──> 准备下单 (交易类)
```

| 搜索分类 | 关键词示例 | 目的与信息信号 | 对应产出选题 |
|---|---|---|---|
| **求助类** | “XX怎么搭”、“XX怎么用”、“XX求助” | 寻找解决方案的人，提取最原始小白痛点 | 基础科普 / 保姆级入门 SOP |
| **吐槽类** | “XX太假了”、“XX不好用”、“XX踩坑” | 对现有方案不满的人，提取被伤害的痛点 | 避坑指南 / 揭秘真相大反差 |
| **替代类** | “有没有比XX更好的”、“XX替代品” | 正在对比选择的人，提取核心决策因子 | 评测对比 / 为什么我们更好 |
| **交易类** | “求XX推荐”、“XX多少钱”、“哪里能买” | 已经准备付费的人，强烈买单信号 | 产品引流笔记 / 案例展示 |

---

## 🛠️ 2. 评论区“信号提取器”规则

1. 点进帖子后，**重点看评论区**（正文可能是营销，评论区才是真实需求）。
2. 当评论区出现：
   - “看懂了但太繁琐，有没有现成的？” → **极佳的虚拟产品信号（发售 39/599元 产品）**
   - “求带”、“多少钱能搞定全套？” → **极佳的高客单私域成交信号（发售 19,800/39,800 元服务）**
3. 自动分流：
   - 适合建信任的内容 → 存入 `01-IP选题库`
   - 适合卖产品的素材 → 存入 `02-产品引流选题库`
