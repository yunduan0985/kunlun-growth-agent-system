# Workbuddy 导入与集成指南

Workbuddy 是一款专注于企业协同和智能体聚合的平台，支持把定制化 Agent 引入团队的日常聊天、知识沉淀和任务执行流中。

以下是导入本合集 30 个 Agent 至 Workbuddy 平台的详细配置步骤。

---

## 步骤一：创建自定义助手

1. 登录 Workbuddy 后端管理控制台。
2. 导航至 **智能助手 / Agent 管理** 页面，点击 **新建助手**。
3. 填入助手基本配置：
   * **助手名称**：填写 `metadata.json` 中的 `name`。
   * **描述**：填写 `metadata.json` 中的 `description`。
   * **头像**：可以使用 `metadata.json` 中提供的建议头像 SVG URL，或者上传团队统一设计的头像。

---

## 步骤二：导入人设指令

1. 在助手的配置页面中，找到 **系统提示词 (System Prompt / Custom Instruction)** 输入框。
2. 完整复制并粘贴对应 Agent 目录下的 `system_prompt.md`。
3. **关键参数配置**：
   * **Temperature (温度)**：
     * 如果是 **选题官、内容生产官、AI设计师** 等，设为 `0.7 - 0.8` 以获得创造力。
     * 如果是 **财务分析师、天眼查、项目经理、风控官** 等，设为 `0.1 - 0.2` 以获得高度准确性和确定性。
   * **Max Tokens**：推荐设置为 `2048` 或更高，防止长文生成和数据分析被截断。

---

## 步骤三：注册与配置 API 工具 (Tools)

Workbuddy 支持通过插件机制让助手调用外部系统。

1. 在 Workbuddy 控制台中，转到 **集成与插件 (Integrations/Plugins)**。
2. 点击 **添加自定义 API 插件**。
3. 在 Schema 导入区，选择 JSON 格式，将对应 Agent 的 `tools.json` 内容完整复制粘贴进去。
4. **端点配置**：
   * 确保 API 地址是可公开访问的，或者是企业内网穿透后的地址（如 `https://api.kunlun-growth.com/video`）。
   * 配置认证信息（API Key / Token Header）。
5. 保存插件，并在您刚才创建的助手页面，勾选开启该插件，允许助手调用。

---

## 步骤四：配置私有数据（知识库库连接）

对于“帅总知识库”、“AI销冠”等：
1. 在 Workbuddy 菜单中，进入 **知识库管理**。
2. 点击新建，命名并上传企业文档（支持 Word、PDF、Markdown 格式）。
3. 开启向量索引，等待处理完成。
4. 返回助手配置，将知识库挂载到对应的助手身上，设置检索相似度阈值（建议设为 `0.6` 以上，避免无关文档干扰）。
