# 💡 行业场景 Prompt 精选集（即插即用版）

> [!TIP] 使用说明
> 找到你的**角色版本**，直接复制括号内的 Prompt 粘贴进 AI 工具，替换 `[...]` 的占位符即可立即使用！

---

## 🎓 校长/教育机构老板版

### P-EDU-01：排课与教务 AI
```
你是一名专业的教务管理助手。
我的培训机构有 [X] 个班级，[X] 名老师，每周课程总计 [X] 课时。
请帮我生成一份本周的最优排课方案，要求：
1. 避免同一老师同一时段排两门课；
2. 照顾学生的核心时间段（周末上午优先）；
3. 以表格形式输出，列为时间段，行为教室。
```

### P-EDU-02：学员学情分析报告
```
以下是我们班 [X] 名学员本周的测试成绩数据：
[粘贴成绩表格]
请帮我生成一份学情分析报告，包含：
1. 班级整体平均分、最高分、最低分；
2. 识别出 3 名需要重点关注的学员及其薄弱知识点；
3. 给家长的个性化反馈信（10句话以内，语气温暖专业）。
```

### P-EDU-03：招生文案撰写
```
我们是 [城市] 的 [科目] 培训机构，主要招 [年级] 学员。
目标家长画像：[月收入/职业/焦虑点]。
请帮我写一篇 200 字以内的招生文案，用于朋友圈发布，
要求：突出学员成绩提升案例，有紧迫感，结尾有行动指引。
```

## 💼 企业老板/创始人版

### P-CEO-01：竞品分析报告
```
请对 [竞品公司名] 进行竞品分析，从以下维度输出：
1. 产品核心功能对比（与我们的差异）；
2. 定价策略分析；
3. 市场口碑（从公开评价中提炼）；
4. 给我们的战略建议（3条）。
用表格 + 要点形式输出，500 字以内。
```

### P-CEO-02：投资人/客户演讲稿
```
我是 [公司名] 的创始人，公司主营业务是 [一句话描述]。
我们的核心优势是 [3个差异化点]。
目前我们已有 [客户数/营收数据/案例]。
请帮我写一段 3 分钟的路演演讲稿，
风格：自信、数据驱动、有画面感、结尾有感情。
```

### P-CEO-03：员工 OKR 制定辅助
```
我们是一家 [行业] 公司，季度核心目标是 [目标]。
请帮我为 [部门/岗位] 设计 3 个 OKR（目标与关键结果），
要求：可量化，可追踪，挑战性与可达性平衡。
```

## 📢 运营/新媒体博主版

### P-OPS-01：小红书爆款标题生成器
```
我要发一篇小红书，核心话题是 [话题]，目标读者是 [人群]。
请帮我生成 10 个爆款标题，要求：
- 使用数字（如"5个方法"、"3天学会"）；
- 带情绪词（焦虑/好奇/惊喜）；
- 字数 20 字以内；
- 含 2~3 个 emoji。
```

### P-OPS-02：朋友圈去 AI 味文案改写
```
原始文案：[粘贴你的 AI 生成文案]

请将以上文案改写成符合以下要求的朋友圈版本：
1. 第一人称，像真实人说话，有口语感；
2. 删除所有"此外"、"综上"、"值得注意"等 AI 腔词汇；
3. 加入 1 个具体的真实细节（可以虚构合理场景）；
4. 总字数控制在 150 字以内；
5. 结尾有一个引发互动的问题或留白。
```

### P-OPS-03：内容矩阵批量生产
```
围绕核心主题 [主题]，请帮我生成一个 7 天内容矩阵计划：
- 每天 1 条内容
- 平台：[小红书/抖音/公众号]
- 格式：标题 + 核心卖点 + 发布时间建议
- 内容类型需多样：教程/对比/故事/工具推荐/案例
以表格形式输出。
```

## 🤝 销售/商务版

### P-SALES-01：陌生拜访开场白
```
我是一名 [行业] 的销售，今天要第一次联系 [客户类型] 客户。
客户的痛点可能是 [痛点]，我们的产品能解决 [价值]。
请帮我写一段 3 句话以内的微信开场白，
要求：不要广告感，像朋友语气，结尾有一个简单的问题引导回复。
```

### P-SALES-02：提案报价邮件
```
客户情况：[客户公司名/行业/规模/需求]
我们的方案：[方案简述]
报价：[金额及组成]
请帮我写一封正式的提案邮件，包含：
- 客户痛点复述（显示我们真的理解了需求）；
- 方案核心价值（3 个关键点）；
- 报价说明（体现 ROI）；
- 下一步建议（明确的行动项）。
字数 300 字以内，语气专业但不冷漠。
```

### P-SALES-03：客户跟进话术
```
背景：我们在 [X] 天前与客户沟通过，客户当时说 [客户的反馈/顾虑]。
至今未回复。请帮我写一条跟进消息，要求：
- 不让人觉得催；
- 带来新的价值（分享 1 个相关案例/洞察）；
- 给客户一个简单的回复理由。
字数 80 字以内。
```
