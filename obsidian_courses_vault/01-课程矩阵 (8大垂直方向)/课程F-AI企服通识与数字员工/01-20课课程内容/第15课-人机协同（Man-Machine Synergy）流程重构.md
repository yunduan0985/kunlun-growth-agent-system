第三节 动手练习：排查你部门的“数字员工替换点”
现在，请大家拿出一张纸，画出你部门在【人机协同新组织架构重塑】流程中的全部细节：
1. 岗位日常例行动作清单；
2. 输入数据格式与审批流程；
3. 输出结果与归档方式；
4. 数据敏感度级别审查。

把这些动作分成两类：
第一类：必须由人类员工亲自做决策与情感沟通的（如高管决策、员工关怀、商务谈判）。
第二类：可以完全交给企业数字员工自动执行的（如简历初筛、发票比对、制度问答、报告初稿撰写）。
你会发现：至少 50% 以上的事务性动作，都可以标准化为数字员工！

步骤二：配置专用的数字员工岗位说明书 Prompt（AGENTS.md）
复制以下标准化规范：

```markdown
# AGENTS.md — 企服 人机协同（Man-Machine Synergy）流程重构 数字员工岗位说明书

## Role Specification
你是企业 [人机协同（Man-Machine Synergy）流程重构] 岗位的专属数字员工。

## Operating Boundaries & Rules
1. 严格遵守企业 PII 数据脱敏规范，严禁泄露核心客户隐私；
2. 输出格式符合公司标准模版，单句独立换行，去 AI 味；
3. 当遇到无法判定的合规风险时，自动转接人类主管处理。

## Input Scope
- 部门原始请求：员工担忧被AI替代产生抗拒心理、不知道如何调整岗位分工

## Workflow Execution
1. 运行 PII 校验；
2. 提取业务关键点；
3. 格式化输出。
```

步骤三：数据脱敏与风控校验
调用 Python 脚本进行掩码测试：

```python
import re

def mask_pii_data(text):
    # 手机号脱敏
    phone_pattern = r'1[3-9]d{9}'
    masked_text = re.sub(phone_pattern, '1XX****XXXX', text)
    return masked_text
```
