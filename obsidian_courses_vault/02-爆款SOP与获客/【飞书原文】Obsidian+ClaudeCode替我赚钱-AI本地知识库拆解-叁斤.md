# 🚀 Obsidian + Claude code，它们正在替我赚钱丨我的 AI 知识库拆解

> **作者**：叁斤 | 自由职业者
> **核心工具**：Obsidian + Claude Code / MCP 工具链
> **核心成果**：一个人干一支团队的活；公众号从月更变日更，1小时写几千字；小红书日产20篇优质搜索笔记；沉淀出2份虚拟产品（39元/599元）。

---

## 💡 为什么你需要自己的 AI 本地知识库？

**传统使用 AI 的方式**：打开对话框 → 粘贴背景 → 拿到回复 → 关掉。每次都要重新解释你是谁、你做什么。

**真正的 AI 知识库方式**：
- **无感加载**：启动时自动加载 400 多行协作规则、技能包与个人经历；
- **全本地化存储**：Obsidian 使用 Markdown 格式，所有文件在本地电脑，AI（如 Claude Code 或命令行 Agent）可以直接读写操作文件；
- **标准流程化输出**：AI 自动搜索关键词、读搜索 SEO 方法论、读产品卖点，再按定义好的写作规范生成，最后自动运行质量自检。

## 📂 知识库全貌与关键设计

### 1. 流水线状态管理（文件夹隔离）
```
知识库/
├── 01-选题库/     ← 待挖掘的爆款选题
├── 02-待发布/     ← AI生成并自检通过的内容
└── 03-已发布/     ← 最终修改发布后的归档
```
- 文章在系统里有具体状态，AI 写完从“选题库”移到“待发布”；
- 操盘手修改发布后，手动/自动移到“已发布”。

### 2. 方法论按【主题】分类，不按【来源】分类
- ❌ 错误做法：按“XX课程”、“XX书籍”分类（找的时候极其痛苦）；
- ✅ 正确做法：按“搜索SEO方法论”、“内容创作方法论”、“营销成交话术”分类。AI 写搜索笔记时直接去“搜索SEO”文件夹读取方法论。

### 3. 产品库与内容库隔离
- **产品库**：卖点、关键词库、价格定位；
- **内容库**：素材、故事、个人定位文件。

## 📜 CLAUDE.md / AGENTS.md：写给 AI 的关键配置文件

放在知识库根目录，AI 启动时自动读取（相当于新员工入职手册）：

1. **你在和谁协作**：作者背景、核心业务、目标人群（按转化效率排优先级）、产品转化路径。
2. **协作原则**：直接给方案不反问、中文优先、全量使用中文标点符号。
3. **行为约束（4条铁律）**：
   - 绝不擅自移动、重命名、删除已有文件；
   - 内容文件只归档不删除；
   - 必须等口令“提交”才执行；
   - 禁止修改其他 Skill 配置文件。
4. **项目索引**：各文件夹用途、文件命名规范、发布流程路径。
5. **任务快速参考**：什么任务调用什么 Skill / Agent。

- **人物档案**：完整背景（换过20份工作、最惨月薪369、怎么做小红书与自由职业），AI 写内容需穿插个人经历时自动调用。

## 🔄 进化系统：让 AI 越写越像你

AI 生成的内容往往缺乏个人独特的文字习惯。构建自我进化机制：

```
1. AI 生成两份文件：一份原始档（原稿），一份放入【待发布】；
2. 操盘手在【待发布】修改为满意版本，发布后移入【已发布】；
3. 积累几篇后，运行【进化学习 (Evolution Skill)】；
4. AI 自动比对原稿与终稿，逐段分析删了什么、改了什么、加了什么；
5. 提炼出跨篇共性规律，写进《个人修改规律库.md》；
6. 下次写文章时，AI 自动读取并遵守这些规律。
```

## 🔌 MCP（Model Context Protocol）：让 AI 连接外部工具

### 1. 小红书 MCP（四路搜索取证法）
- **求助类**：“XX怎么搭/怎么用” → 找正在寻找解决方案的人；
- **吐槽类**：“XX太假了/不好用” → 找对现有方案不满的人；
- **替代类**：“有没有比XX更好的” → 找在对比选择的人；
- **交易类**：“求XX推荐/多少钱” → 找准备付费买单的人。
- AI 点进正文与评论区，提取痛点关键词，自动分流到 IP 选题库或产品引流选题库。

### 2. 日历与提醒事项 MCP
- 结合苹果自带日历/提醒事项，记录工作时间、做周复盘；
- AI 同时读取日历（做了什么）与知识库（产出了什么），分析时间分配效率。

## 💰 虚实结合与知识库变现

1. **变现产品生成**：把在 Obsidian 中沉淀的书籍精读笔记、速读指南、思维模型（如《行为学与人性底层认知》），直接同步打包为知识库产品（如 39 元 / 599 元电子指南）。
