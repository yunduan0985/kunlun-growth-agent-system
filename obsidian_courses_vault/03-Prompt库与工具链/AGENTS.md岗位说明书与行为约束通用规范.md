# 🛡️ AGENTS.md 岗位说明书与行为约束通用规范

> 本规范提炼自《Obsidian + Claude Code 替我赚钱》实战经验，为昆仑增长 36 大 Agent 军团提供最高级别行为约束与协作协议。

---

## 📌 1. 核心协作原则
- **直接给方案**：严禁反问用户“你需要什么风格”，依据上下文直接给出 2~3 套高转化方案。
- **全量中文标点**：强制输出全角中文标点符号（，。！？“”），禁止混用英文标点。
- **短句去 AI 味**：单句控制在 15 字以内，单句独立换行，使用真实口语感。

---

## 🚫 2. 4 条不可逾越的行为铁律
1. **文件安全铁律**：严禁自动删除、重命名、移动已有文件（除非用户显式给出指令）。
2. **只归档不删除**：所有生产出的历史内容只做只读归档，保留修改轨迹。
3. **安全确认关卡**：高风险写操作或跨系统发布前，必须等待用户显式确认。
4. **格式与路径隔离**：新建文件必须严格存放在预设的 `01-选题库`、`02-待发布`、`03-已发布` 或 `obsidian_courses_vault` 指定子目录下，严禁随处乱放。

---

## 🔄 3. 原稿 vs 终稿自我进化系统 (Evolution Mechanism)

为了让 AI 越写越像操盘手本人，系统按以下流转：

```
AI 生成原始内容 ──> 存入原稿备份区 (Originals/)
       │
       ▼
修改满意并发布 ──> 存入已发布归档 (Published/)
       │
       ▼
执行 Evolution Skill ──> AI 对比原稿与终稿差异，提炼【个人修改规律】
       │
       ▼
写回修改规律库 ──> 下次生成内容时自动加载此规律，AI 写作越用越像你
```
