第四节 步骤分解与手把手实操 SOP

步骤一：数据/文档结构化导入
把【多项目并行进度管理与周报】相关的大篇幅 PDF、Excel 或会议录音转写文本整理好。

步骤二：配置专用的结构化办公 Prompt（提示词）
复制以下提示词到控制台：

```markdown
# Role: 顶级智能办公与风控分析 Agent
## Context: 针对办公场景 [多项目并行进度管理与周报]

## Constraints (办公严谨性与去 AI 味铁律)
1. 绝不凭空捏造任何数据或条款，所有结论必须有原文引用支持；
2. 总结简明扼要，采用列表化输出，主谓宾清晰；
3. 对风险点与废标条款进行【红色高亮/重点标注】；
4. 输出结果格式符合公司标准公文/报告规范。

## Execution Flow
1. 扫描长文档核心结构；
2. 比对资质与关键风险点；
3. 输出结构化总结报告。
```

步骤三：Python 数据校验与自动比对
运行 Python 校验脚本：

```python
def validate_contract_terms(text):
    risk_keywords = ["违约金无上限", "单方终止权", "管辖法院变更"]
    risks = [k for k in risk_keywords if k in text]
    return {"has_risk": len(risks) > 0, "risks_found": risks}
```
