# 🧩 [CONTENT-01] 权威背书转化为爆款内容拼图

**分类**：内容营销类（CONTENT 系列）
**触发场景**：获得任何新的权威背书时（平台上榜 / 获奖 / 媒体报道 / 大品牌合作）
**输出物**：朋友圈文案 + 小红书图文套装 + 封面图指令

---

## 核心公式

```
反差感（小我 vs 大平台）
  + 成长故事线（不是直接晒结果）
  + 核心数据（1~2个最有冲击力的数字）
  + 低门槛行动号召
= 爆款内容
```

---

## 执行步骤

```
Step 1: 找反差
  → 「我（小个体）」vs「平台/品牌（权威大）」
  → 「之前（普通）」vs「现在（被认可）」

Step 2: 提炼数字
  → 最有视觉冲击的 1~2 个（名次/下载量/时间/金额）
  → 例：「腾讯旁边 第四位 6.5万下载 7天」

Step 3: 套模板生成
  → 朋友圈：意外感开场 + 故事线 + 结果 + 真实收尾 + CTA
  → 小红书：数字标题 + 故事正文 + 方法论 + 评论互动CTA

Step 4: 配图
  → 大字报封面：核心数字放最大，深色背景，金色/蓝色主色
  → 原始截图：展示真实平台页面（不裁剪，真实感）

Step 5: 发布执行
  → 参考：[[朋友圈+小红书内容营销完整SOP与模板库]] 发布清单
```
