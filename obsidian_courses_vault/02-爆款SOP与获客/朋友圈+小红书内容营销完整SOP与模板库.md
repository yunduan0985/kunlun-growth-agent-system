# 📱 朋友圈 + 小红书 内容营销完整 SOP

> [!IMPORTANT] 核心方法论
> **「将权威背书转化为爆款内容」三步公式**
> 1️⃣ 找到「反差感」（小个体 vs 大平台/大品牌）
> 2️⃣ 用「故事线」串联成长过程（不要直接晒结果）
> 3️⃣ 结尾留「低门槛行动号召」（评论/私信，不要让人扫码）

---

## 一、朋友圈文案模板库

### 🏆 模板 A：「成就反差型」（适用于：获奖/上榜/被认证）

**触发条件**：任何权威平台排名 / 媒体报道 / 官方认证

**结构公式**：
```
[意外感开场] + [成长故事线] + [结果数据] + [真实感收尾] + [低门槛CTA]
```

**实战样本（腾讯SkillHub第四版本）**：
```
说实话，做这件事之前没想到会做到这一步。

最开始只是想把自己公司用的 AI 工作流整理清楚，
后来整理成了 36 个 Agent，后来开始教别人用，
后来腾讯 SkillHub 把我们认证了，再后来就变成了这张图。

腾讯旁边，第四位，6.5 万下载。

没有刷的，就是 7 天时间一点一点做出来的。

2026 年做 AI 落地这件事，我觉得还很早。

——有在认真考虑用 AI 替自己打工的，可以来聊聊。
```

**评论区第一条（自己发）**：
```
顺手放一下我们在 SkillHub 的企业主页，感兴趣的可以看看我们做了什么 👇
skillhub.cloud.tencent.com/enterprise-zone
```

**结构公式**：
```
[学员结果数据] + [对话截图/引用] + [方法论一句话] + [引流CTA]
```

**模板框架**：
```
[学员昵称] 今天发来消息，我看了三遍。

```

## 二、小红书图文套装模板

### 📋 套装结构（每次发布必须包含）

| 元素 | 内容 | 备注 |
|---|---|---|
| **封面图** | 大字报式，核心数据放最大 | 比例 3:4，深色背景 |
| **标题** | 数字+反差+悬念 | 20字以内 |
| **正文开头** | 一句打破预期的话 | 不要"今天分享" |
| **正文主体** | 故事线+数据+方法论 | 300~500字 |
| **结尾CTA** | 评论区扣数字/问问题 | 不要让人扫码 |
| **话题标签** | 8~10个，大话题+小话题混搭 | 见下方标签库 |

---

## 四、「将权威背书转化为内容」的通用拼图

> 注册为原子拼图：`CONTENT-01_权威背书转化为爆款内容`

**触发场景**：任何新的权威背书出现（平台排名/获奖/被媒体报道/与大品牌合作）

**执行步骤**：
```
Step 1: 找反差感
  → 「我（小）」vs「平台/品牌（大）」的对比
  → 「之前（弱）」vs「现在（强）」的成长线

Step 2: 提炼核心数据
  → 最有冲击力的 1~2 个数字（名次/下载量/时间）

Step 3: 套模板生成内容
  → 朋友圈：模板A（成就反差型）
  → 小红书：故事线+数据+方法论+CTA

Step 4: 配图
  → 大字报式封面：核心数据放最大字号
  → 原图截图：展示真实平台页面

Step 5: 发布 + 30分钟操作清单
```
