# 🎙️ 音视频转写与全电脑资产整理 SOP

> **目的**：指导异地 Windows 电脑及本台电脑，将积压的音频、视频录音、演讲素材与乱七八糟的文档，全自动转写为结构化 Markdown，全量归纳沉淀入 Obsidian 知识库。

---

## 🛠️ 1. 音视频极速转写与 Markdown 清洗 3 步走

```
[原始音视频文件 (.mp4/.mp3/.m4a)]
                 │
                 ▼ (Whisper / FunClip / 剪映 / 阿里转写 API)
      [导出带时间戳的字幕文本 (.txt/.srt)]
                 │
                 ▼ (Agent 去口水话、独立短句、去 AI 味清洗)
   [结构化 Markdown 出版级逐字稿 (存入 Obsidian)]
```

### 具体操作：
1. **转写获取文本**：使用本地 Whisper 或在线转写工具把音视频转为文本或字幕；
2. **存入指定目录**：把转写出的文本放入 Obsidian 的 `00-个人流水线工作台/01-选题库/` 或对应课程目录下；
3. **Agent 自动清洗**：Agent 自动进行去口水话、分段、提取摘要金句，并自动注入 `STATE.json` 与主索引！

---

## 📂 2. 整台电脑非结构化文档整理归纳标准

- **课程/讲义/课件** $\rightarrow$ 归入 `01-课程矩阵 (8大垂直方向)/`
- **演讲/音视频逐字稿** $\rightarrow$ 归入 `02-爆款SOP与获客/` 或 `00-个人流水线工作台/`
- **代码/项目/SaaS** $\rightarrow$ 归入 `09-GitHub远程资产与1500iOS应用中枢/`
- **个人心得/日记/随想** $\rightarrow$ 归入 `00-个人流水线工作台/04-方法论/`
