# 飞书 (Feishu) 集成与导入指南

本文档将详细指导您如何将本合集中的 30 个 Agent 导入至飞书生态中。飞书目前提供了两种最方便的 AI 集成方式：**多维表格 (Feishu Base) 中的 AI 字段** 和 **自定义群聊机器人 (Webhooks & API)**。

---

## 方案一：使用多维表格 (Bitable) AI 任务字段（推荐）

飞书多维表格原生支持 AI 任务字段，允许直接对表格内的数据行进行 AI 提取、润色、润色和自动化流程。这是导入内容组、数据组、管理组 Agent 最低成本、最强大的方案。

### 1. 导入步骤
1. 打开您的飞书多维表格。
2. 新增一个字段，选择字段类型为 **AI 任务**。
3. 在“角色设定”中，复制并粘贴本合集中对应 Agent 的 `system_prompt.md`（例如内容组的 `topic_selector/system_prompt.md`）。
4. 在“任务输入”中，选择关联的表格字段（例如：“原始选题灵感”或“抓取到的竞品文案”）。
5. 点击“生成预览”进行调试。

### 2. 绑定外部工具 API (OpenAPI 导入)
如果 Agent（如：天眼查、视频转录助手）需要使用工具：
1. 在多维表格 AI 任务的高级设置中，找到“连接工具 / API”。
2. 选择“新建工具 -> 导入 OpenAPI Schema”。
3. 复制对应 Agent 目录下的 `tools.json` 中的 OpenAPI 内容并贴入。
4. 配置基础路径 (Base URL) 为您本地部署的微服务或 MCP 代理地址（例如：`http://your-server-ip:8000`）。
5. 这样，AI 字段在运行过程中就会根据需要自动向该接口发起请求。

## 方案二：配置飞书自定义群聊机器人

如果您希望在群聊中通过 `@机器人` 提问、生成日报、进行财务咨询或翻译，可以配置自定义机器人。

### 1. 通过中转平台对接（Coze / Dify）
由于飞书原生自定义群机器人仅支持接收 Webhook，无法直接进行大模型会话，目前最普遍的方案是使用 **Coze (扣子)** 或 **Dify** 充当中间网关。

1. **在 Dify/Coze 平台搭建 Bot**：
   * 按照 [Coze/Codex 导入指南](file:///Volumes/MOVESPEED/下载/AIcode/Agent/docs/coze_codex_integration.md) 将 Agent 的 Prompt、工具和知识库配置好。
2. **在飞书开放平台创建企业自建应用**：
   * 登录 [飞书开放平台](https://open.feishu.cn/)，点击“创建企业自建应用”。
   * 进入“凭证与基础信息”，记录 `App ID` 和 `App Secret`。
   * 进入“机器人”页面，开启机器人功能。
3. **绑定事件订阅**：
   * 在 Coze/Dify 平台的“发布 -> 飞书渠道”中，复制生成的“验证 Token”和“Encrypt Key”。
   * 回到飞书开放平台，粘贴至“事件订阅”页面。
   * 在飞书“版本管理与发布”中，申请发布该应用。
4. **使用**：
   * 将该机器人拉入飞书群聊，@机器人 即可直接调用对应的 Agent 服务。

## 方案三：飞书捷径 (Lark Flow) 自动化触发

对于“微信数据专员”、“X检索官”和“风控官”等需要监听数据并自动报警或转发的 Agent，可以使用飞书捷径。

1. 打开飞书，进入“工作台 -> 捷径”。
2. 创建新捷径，选择触发器（Trigger），例如：
   * **当多维表格有新记录时**（例如情报收集者抓取到了新竞品消息）。
   * **当飞书群聊收到特定消息时**。
3. 添加动作：**调用大模型 / AI 模块**。
4. 将 Agent 的 `system_prompt.md` 作为提示词传入，并将触发器捕获的文本作为输入。
5. 添加后续动作：**发送飞书群消息** 或 **发送邮件通知**，实现自动化流。
