# 🚀 IMA 收，Obsidian 炼，飞书享，Codex 调：个人与团队 AI 内容流水线拆解

> **作者**：石老师 | 生财有术航海家/线下大课讲师
> **核心架构**：IMA (收) + Obsidian (炼) + 飞书 (享) + Codex/Agent (调)
> **核心亮点**：读取微信本地历史数据库，自动挖掘选题与客户痛点；Hermes 手机微信远程指挥本机 Agent；语料块 (Atomic Block) 化管理与严格验收机制。

---

## 💡 核心底层公式与四大工具分工

```
手机文章 / 微信记录 / 电脑网页 / 客户咨询
       │
       ▼ (收)
 IMA / Obsidian Inbox / 微信本地 Vault
       │
       ▼ (调)
  Agent / Codex 读取、拆分语料块
       │
       ▼ (炼)
 Obsidian Notes (单观点/单案例语料块 & 双向链接)
       │
       ▼ (享)
 飞书云文档 / 知识库排版 & 交付
       │
       ▼ (输出)
 公众号 / 短视频 / 朋友圈 / 课程 / B端方案
```

### 工具分工表
| 工具 | 唯一职责 | 使用场景 |
|---|---|---|
| **IMA (腾讯AI知识库)** | **收** | 手机端/微信随手临时保存文章网页，基于已保存网页快速问答 |
| **Obsidian** | **炼** | 本地 Markdown，拆分观点、建立双链、沉淀核心语料块 |
| **飞书** | **享** | 需要排版、评论、团队协作、交付给客户或公开阅读时 |
| **Codex / Agent** | **调** | 自动化读取、整理、拆分语料、微信数据库解密、跨平台写入与验收 |

## 🛠️ 微信本地数据库解密与痛点挖掘 (`yichen-wechat-local-vault`)

### 1. 为什么读取微信记录是极佳选题库？
真实客户在微信里的提问、吐槽、买单对话，包含最真实的用户痛点与意图信号。

### 2. 命令行解密与只读查询 SOP
```bash
# 1. 运行增量刷新解密本地数据库 (不修改微信原库，安全隔离)
~/.codex/skills/yichen-wechat-local-vault/.venv/bin/python \
~/.codex/skills/yichen-wechat-local-vault/scripts/decrypt_all_dbs.py --mode incremental

# 2. 限定范围查询（例如：查询过去 7 天包含某关键词的记录，最多 20 条）
```

## 📱 Hermes 手机微信远程指挥 Agent SOP

通过 `Hermes` 作为微信接入层与安全调度层：
- 手机在微信发送指令 → Hermes 校验安全与权限 → 唤醒本机 Agent 调用 `yichen-wechat-local-vault` → 将提炼结果回传至手机微信。
- **安全铁律**：私聊仅限本人账户，群聊关闭，严禁无限制导出与输出密钥/wxid。

---

## 📑 语料块 (Atomic Block) 化管理与 4 状态水库

取消“整篇收藏”，全面采用“语料块”：**一条语料块只保留一个可以独立使用的观点、案例或数据**。

```
Inbox (新进原料) ──> Notes (提炼的独立语料块) ──> Outputs (成品输出)
                          │
                          ▼
                       Archive (原文存档)
```

---

## ⚠️ 目标端真实验收标准（反对“接口欺骗”）

“**接口返回成功 ≠ 真正完成！**” 必须执行笨但极度有效的目标端读回验收：

| 校验终端 | 必须看到的结果 | 不能算成功的情况 |
|---|---|---|
| **Obsidian** | 文件在正确目录下，标题、首尾段落、来源链接均能读回 | 只在终端看见生成了文件名 |
| **IMA** | 按标题重新搜索，能打开并读到完整正文 | 仅看到 API 接口返回 200 |
| **飞书** | 目标知识库节点下能搜到文档，排版与表格完整 | 仅在个人云盘根目录新建了文档 |
| **微信Vault** | 目标会话唯一，命中数量明确，抽查与原记录一致 | 拿旧快照或同名群聊充数 |
